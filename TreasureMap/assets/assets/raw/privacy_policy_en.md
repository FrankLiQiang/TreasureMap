This application values user privacy.
This policy explains how information is handled within the application.

## 1. Information Collection

This application does not collect, upload, or store users’ personal file contents.

No account system is provided.
No cloud storage service is offered.

All data processing is performed locally on the user's device.


## 2. Permissions

To provide the app's functionality, this application may request the following permissions:

Storage access: used to read files and hide files into host images, and for encryption and decryption of those files.

Media access: used to save hidden information into host images.

The above permissions are used only to implement the app's features and are not used for data collection.


## 3. Data Transmission

This application does not transmit user data to external servers.
No user file content is shared with third parties.


## 4. Data Security

All files remain on the user's device.
Users are responsible for safeguarding their passwords and device security.

Password recovery is not supported.


## 5. Third-Party Services

This application does not integrate advertising services.
No analytics services are included.
If third-party services are added in the future, this policy will be updated accordingly.


## 6. Policy Changes

This policy may be updated in accordance with legal or functional changes.
Updates will be announced within the application.

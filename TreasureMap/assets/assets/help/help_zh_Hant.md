
## 1. 如何更改／刪除隱藏檔案？

若要修改隱藏檔案，請在「檔案」頁面 → 「選擇檔案」，重新選擇已修改的檔案，然後以「加密」保存，該變更才會寫回圖片。
要取消隱藏，請在「檔案」頁面點選「取消選擇」，並以「加密」保存。
正常退出或切換時會刪除解密後的隱藏檔案；異常退出可能會遺留該檔案。

## 2. 如何對檔案自身加密（不依賴宿主圖片）？

在「檔案（自身）」頁面，可對檔案以密碼進行單獨加密（無需圖片）。此方式生成的加密檔案僅能由本應用解密，請妥善保管密碼，無法找回。

本應用無法總是判斷密碼是否正確。如果使用錯誤密碼進行解密而導致檔案無法被其他軟體開啟，請使用相同（剛剛錯誤輸入的）密碼再次操作以回復到解密前的狀態。

## 3. 如何刪除原圖？覆蓋規則是什麼？

宿主圖片：在 Windows 與 macOS 上，執行「加密」儲存會覆蓋原始圖片檔案；在 Android 與 iOS 上，每次加密儲存會另存為新圖片，是否刪除原圖由使用者自行決定。
隱藏檔案：解密後的隱藏檔案若與目的資料夾中已有同名檔案，是否覆蓋由使用者自行決定。
檔案本體：透過本應用解密或匯出／加密產生的檔案，若與目的資料夾中存在同名檔案，是否覆蓋由使用者自行決定。

## 4. 如何更改圖片密碼？

使用原密碼打開圖片，於「選擇圖片」→「加密」中輸入新密碼兩次確認，系統會將資訊儲存到圖片中，完成圖片密碼的變更。

## 5. 如何更換宿主圖片？

在解鎖原圖後，點選「選擇圖片」選擇新圖，然後點「加密」即可將嵌入資訊寫入新圖；原圖會保留，除非使用者手動刪除。


## 6. 對宿主圖片，如何傳輸與分享？什麼是校驗碼？

跨平台或裝置傳送時，請務必傳送原始圖片檔案，否則可能無法正確解密。在「選擇圖片」畫面點選「複製校驗碼」可以複製該圖片的校驗碼。只有校驗碼相同的圖片，才能還原出相同的隱藏資訊。

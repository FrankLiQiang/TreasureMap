## 1. How to change/remove a hidden file?

If you want to modify a hidden file, open the File screen → "Select File", reselect the modified file, then save using "Encrypt" to write the change back into the image.
To stop hiding a file, tap "Deselect" on the File screen and save with "Encrypt".
When you exit normally or switch files, the decrypted hidden file is deleted; an abnormal exit may leave it behind.

## 2. How to encrypt a file without a carrier image?

In the "File (Self)" screen you can encrypt a file with a password without using an image. Encrypted files created this way can only be decrypted by this app—keep passwords safe, there is no recovery.

The app cannot always tell whether a password is correct. If you decrypt with the wrong password and the resulting file cannot be opened by other software, use the same (incorrect) password again to restore the file to its pre-decrypted state.

## 3. How do I delete the original image? What are the overwrite rules?

Carrier image: On Windows and macOS, an encrypted save will overwrite the original image. On Android and iOS, each encrypted save creates a new image; the user may choose whether to delete the original.
Hidden file: For a decrypted hidden file, the user can decide whether to overwrite a same‑named file in the destination folder.
File itself: For files produced by decrypting or encrypting, the user can decide whether to overwrite a same‑named file in the destination folder.

## 4. How to change an image's password?

Open the image with the current password, go to "Select Image" → "Encrypt", enter the new password twice and confirm to save the information into the image and change its password.

## 5. How to replace the carrier image?

After unlocking the original image, tap "Select Image", choose the new image, then tap "Encrypt" to write the embedded information into the new image. The original image remains unchanged unless you delete it manually.

## 6. How do I transfer and share the carrier image? What is the verification code?

When transferring images between platforms or devices, always send the original image file; otherwise decryption may fail. 
On the Select Image screen, tap the "Copy Verification Code" button to copy the image's verification code. Only images with the same verification code will decrypt to the same embedded data.
